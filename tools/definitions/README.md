# Définitions d'outils

Contrats JSON de référence pour les outils Internet.

| Fichier | Outil |
|---|---|
| `web_search.json` | recherche web |
| `web_fetch.json` | extraction du texte d'une URL |
| `web_browse.json` | navigation Playwright |
| `screenshot_page.json` | capture d'une page |

Le schéma transmis au modèle est celui de `ITool.InputSchema`. Le catalogue complet et la procédure
de création d'un outil sont dans [docs/tools.md](../../docs/tools.md).
